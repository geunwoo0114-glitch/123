예약·기록

예약 글은 이 프로그램이 켜져 있는 동안 30초마다 확인해서 올립니다. 컴퓨터가 꺼져 있었다면 오래 지난 예약은 자동으로 올리지 않고 '실패(놓침)'로 남깁니다.

Threads 계정 연결

Meta 개발자 앱에서 발급한 Threads 액세스 토큰을 붙여 넣고 저장한 뒤 연결 확인을 누르세요. 방법은 '요건 안내' 탭에 있습니다.

광고 표시

모든 글에 자동으로 붙습니다. 공정위 지침은 '광고'처럼 명확한 말을 글 첫 부분(또는 끝 부분)에 본문과 구분해 적도록 안내합니다.

발행 속도

Meta 한도는 24시간 250개지만, 같은 제휴 링크 글을 몰아 올리면 스팸으로 보일 수 있어 훨씬 낮게 둡니다.

바로 되는 것상품·제휴 링크 저장, 광고 문구 자동 첨부, 글자 수·링크·위험 표현 검사, 사람 확인 후 예약, 발행 상태·실패 기록, 실패 시 자동 재시도(최대 3번)

Threads 토큰 받기 (요약)

  1. Meta for Developers에서 앱을 만들고 Threads API 사용 사례를 추가합니다.
  2. 권한 threads_basic, threads_content_publish를 켭니다.
  3. 앱 역할에서 내 Threads 계정을 테스터로 추가하고, Threads 앱(설정 → 계정 → 웹사이트 권한)에서 초대를 수락합니다.
  4. 사용 사례 화면의 토큰 생성 도구로 토큰을 만들어 장기 토큰(60일)으로 바꾼 뒤 설정에 붙여 넣습니다.
  5. 60일이 되기 전에 설정의 토큰 60일 연장을 눌러 주세요(발급 24시간 뒤부터 가능).

Meta 화면 구성은 자주 바뀝니다. 위 순서가 다르면 Threads API 공식 문서를 따르세요. 다른 사람 계정까지 올리려면 Meta 앱 검수가 필요합니다.

광고 표시 · 운영 주의

  • 제휴 링크가 있는 글은 모두 광고 표시가 필요합니다. 프로필·댓글에만 적거나 '더보기'를 눌러야 보이게 하면 안 됩니다.
  • 'sponsored', 'partner', 'thanks to'처럼 모호한 표현 대신 '광고', '협찬'처럼 명확하게 쓰세요.
  • 써 보지 않은 상품을 후기처럼 쓰거나, 근거 없는 '최저가·1위·효과 보장'은 표시광고법 위반이 될 수 있습니다.
  • 정확한 요건은 공정위 「추천·보증 등에 관한 표시·광고 심사지침」과 쿠팡 파트너스 운영 정책 원문을 확인하세요. 이 프로그램의 검사는 실수를 줄이는 보조 장치일 뿐 법률 검토가 아닙니다.
