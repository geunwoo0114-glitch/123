# 🧵 Threads 예약 발행 (쿠팡 파트너스용)

상품과 제휴 링크를 등록해 두고, 소개 글 초안을 만들어 **직접 확인한 뒤** 원하는 시간에 Threads에 올리는 프로그램입니다.
광고 표시 문구는 자동으로 붙고, 발행 상태와 실패 기록이 남습니다.

> 이 프로그램은 "Claude로 쿠팡 파트너스 Threads 예약 프로그램을 만들어 글 24개를 예약했다"는 Threads 게시글을 보고 만들었습니다.
> 원문에는 코드·API·상품 선정 방식이 공개되지 않았고, 수익 주장도 검증할 수 없습니다. 아래 구조는 원문을 재현한 것이 아니라
> **공식적으로 지원되는 방식으로 같은 일을 하도록 새로 설계**한 것입니다.

## 흐름

```
상품·제휴 링크 등록 ─▶ 초안 만들기(Claude 또는 직접) ─▶ 최종 글 확인(광고 문구·링크 포함, 자동 검사)
   ─▶ ☑ 확인 체크 후 예약(여러 개는 간격 두고) ─▶ 예약 시간에 Threads API로 발행 ─▶ 발행됨 / 재시도 / 실패 기록
```

| 탭 | 하는 일 |
|---|---|
| 상품 | 상품 이름, 제휴 링크, **직접 확인한 정보**, **실제 사용 경험**(있을 때만) 저장. 초안 1~5개 생성 |
| 초안 확인 | 실제로 올라갈 글 미리보기, 글자 수(500자), 검사 결과(⛔ 막음 / ⚠️ 경고). 여러 개 골라 시작 시간·간격으로 예약 |
| 예약·기록 | 예약·발행·실패 목록, Threads 링크, 단계별 기록, 예약 취소, Meta 발행 한도 확인 |
| 설정 | Threads 토큰·계정 연결, 광고 문구와 위치, 발행 속도 제한, Claude 키·말투 |
| 요건 안내 | 아래 요건 요약 |

## 시작하기

1. [Node.js LTS](https://nodejs.org/ko/download)(20 이상)를 설치합니다.
2. `start-windows.bat`(윈도우) 또는 `start-mac.command`(맥)를 더블클릭합니다. 브라우저에 `http://localhost:4949`가 열립니다.
3. **설정**에서 Threads 토큰을 넣고 **연결 확인**을 누릅니다. 초안 자동 생성을 쓰려면 Claude API 키도 넣습니다.

```bash
npm install
npm start          # 프로그램 화면
npm run typecheck && npm test
```

⏰ **예약 글은 이 프로그램이 켜져 있는 동안에만 올라갑니다.** 꺼져 있는 동안 예약 시간이 지나면, 다시 켰을 때 60분(설정 가능) 넘게 지난 글은
자동으로 올리지 않고 '실패(놓침)'로 남깁니다. 늦게 올라가는 글이 생기지 않게 하려는 것입니다. 항상 켜 둘 컴퓨터나 서버가 없다면 아래 "다음 단계"를 보세요.

## 조사 결과: 공식 방식과 요건

### Threads에 글 올리기: Meta 공식 Threads API
- 게시는 두 단계입니다. 먼저 `POST /{user-id}/threads`(`media_type=TEXT`, `text`, `link_attachment`)로 컨테이너를 만들고, 다음에 `POST /{user-id}/threads_publish`로 발행합니다. Meta는 발행 전에 컨테이너 상태(`status`)를 확인하라고 권장합니다.
- 텍스트 글은 **500자**까지입니다. 제3자 안내에 따르면 링크는 글 하나에 서로 다른 주소 5개까지입니다.
- 한 계정이 API로 올릴 수 있는 글은 **24시간에 250개**입니다(`threads_publishing_limit`로 조회).
- 권한은 `threads_basic`과 `threads_content_publish`가 필요합니다. 내 계정만 쓸 거라면 앱에 내 계정을 테스터로 추가해 토큰을 받으면 됩니다(개발 모드에서는 보통 앱 검수 없이 쓸 수 있음). 다른 사람 계정까지 쓰려면 Meta 앱 검수가 필요합니다.
- API에는 예약 시간 매개변수가 확인되지 않습니다. 그래서 이 프로그램이 정해진 시간에 위 두 단계를 직접 실행합니다.
- 화면을 자동으로 조작하는 매크로나 스크래핑 방식은 쓰지 않습니다. 약관 위반이 될 수 있고 계정이 정지될 위험이 있습니다.

### 광고 표시: 공정위 「추천·보증 등에 관한 표시·광고 심사지침」
- 쿠팡 파트너스 링크가 들어간 SNS 글은 경제적 이해관계를 밝혀야 합니다.
- 표시는 **글 첫 부분 또는 끝 부분**에 본문과 구분해서 합니다. 댓글이나 프로필에만 적거나, '더보기'를 눌러야 보이는 위치는 인정되지 않습니다.
- 문구는 '광고', '협찬'처럼 명확해야 합니다. 'sponsored', 'partner', 'thanks to' 같은 모호한 표현은 안 된다고 안내되고 있습니다.
- 흔히 쓰는 쿠팡 문구는 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다"입니다. 이 프로그램은 기본값으로 앞에 **[광고]** 를 붙입니다.
- 써 보지 않은 상품을 후기처럼 쓰거나 근거 없이 '최저가·1위·효과 보장'이라고 쓰면 문제가 될 수 있습니다. 그래서 Claude 초안은 사용자가 적은 정보와 경험만 사실로 쓰도록 지시하고, 검사에서도 걸러냅니다.

> ⚠️ 이 프로그램이 일하는 환경에서는 Meta·쿠팡·공정위 사이트에 직접 접속하지 못했습니다. 위 내용은 검색 결과와 해설 자료로 확인한 것입니다.
> 쓰기 전에 [Threads API 문서](https://developers.facebook.com/docs/threads), 공정위 심사지침 원문, 쿠팡 파트너스 운영 정책을 한 번 직접 확인하세요.
> 자동 검사는 실수를 줄여 주는 보조 장치일 뿐 법률 검토가 아닙니다.

## 안전장치

- **사람이 확인해야 예약됩니다.** 예약 요청에 "최종 내용 확인" 체크가 없거나 ⛔ 검사 항목이 있으면 아무 글도 예약하지 않습니다. 예약된 글은 확인한 순간의 최종 글 그대로 올라갑니다.
- **같은 글이 두 번 올라가지 않게 막습니다.** 컨테이너 ID를 먼저 저장해 두고, 다시 시도할 때 이미 발행됐는지 확인합니다. 발행 도중 프로그램이 꺼진 글은 자동으로 다시 올리지 않고 확인을 요청합니다.
- **재시도:** 네트워크·서버 오류나 한도 초과는 2분, 10분, 30분 뒤에 다시 시도합니다. 토큰 만료나 Threads 거절처럼 다시 해도 안 되는 오류는 바로 실패로 남깁니다.
- **속도 제한:** 내 한도가 기본으로 24시간 8개, 글 사이 60분입니다. Meta 한도(250개)보다 훨씬 낮게 잡았습니다. 같은 링크 글을 몰아서 올리면 스팸으로 분류될 수 있기 때문입니다.
- 토큰과 키는 내 컴퓨터의 `settings.json`에만, 상품과 글은 `data.json`에만 저장됩니다. 둘 다 git에 올라가지 않습니다. 프로그램은 `127.0.0.1`에서만 열립니다.
