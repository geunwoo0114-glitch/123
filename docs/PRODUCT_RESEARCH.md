# 다락 — 경쟁 서비스 비교 & 보완 포인트

> "피드를 소비하는 SNS가 아니라 사람의 공간을 방문하는 SNS." · "콘텐츠보다 사람이 먼저 보이는 SNS."

이 문서는 초기 프로토타입을 만들며 다른 SNS/플랫폼과 비교해 **무엇을 가져왔고(채택)**, **무엇을 일부러 뺐고(배제)**,
**무엇이 아직 비어 있는지(보완 과제)**를 정리한 것이다.

## 1. 한눈에 비교

| 서비스 | 그들이 잘하는 것 | 다락이 가져온 것 | 다락이 일부러 피한 것 |
|---|---|---|---|
| **싸이월드(원조)** | 미니홈피, 일촌·일촌명, 방명록, TODAY/TOTAL, 미니미·미니룸, BGM, 도토리 | 개인 공간 중심 구조, **우리 사이 이름(일촌명)**, 메모지형 방명록·비밀글, **TODAY/TOTAL 카운터**, 미니룸, 공식 임베드 BGM, 재화(밤톨) | 유료 결제 중심 꾸미기, 저작권 불분명한 음원 판매 |

## 2. 리서치에서 얻은 근거

- 2026년 Z세대는 공개 피드보다 **친한 사람과의 사적 공유**로 이동 중. Locket은 공개 피드·알고리즘·무한 스크롤 없이 신뢰하는 친구 중심으로 성장했다.
  → 다락은 공개 범위를 4단계(전체/친구/친한 친구/나만)로 두고, 피드를 시간순·친구 중심으로 설계했다.
- Instagram Z세대 사용자 활동의 상당 부분이 DM과 "부계정(친한 친구용 비공개 계정)"에서 일어난다.
  → **1:1 쪽지(DM)**가 다음 핵심 보완 과제다(아래 3장).
- BeReal은 하루 한 번 알림이라는 강한 장치로 폭발했지만 지속하지 못했다.
  → 다락은 강제 알림 대신 **'오늘의 질문'**(날짜별 순환 프롬프트)으로 기록 문턱만 낮춘다.

## 3. 이번 프로토타입에서 보완·추가한 것

1. **우리 사이 이름(일촌명)**: 친구 신청 때 서로를 부르는 이름을 정하고 공간/친구 목록에 표시.
2. **친한 친구 공개 범위**: Instagram Close Friends처럼 게시물·다이어리·사진첩에 적용.
3. **상태 메시지 스트립**: 홈 상단에 친구들의 상태가 말풍선으로. 24시간 내 바뀐 상태는 강조 링.
4. **방문 흔적(opt-in)**: TODAY/TOTAL은 모두 집계하되, '누가 왔는지'는 방문자가 허용한 경우에만. 공개 여부는 공간 주인이 선택.
5. **미니룸**: 공간 주인의 미니미가 자기 방에 앉아 있는 장면(향후 2D 가구 배치 → 3D 공간으로 교체될 자리).
6. **미니게임 타운**: 무료 미니게임 + 출석 → 밤톨 → 상점 → 옷장. 서버가 시작 시각을 기록해 점수 타당성을 검증하고, 하루 보상 상한을 둔다.
7. **오늘의 질문 / 지난 오늘**: 다이어리 작성 동기 부여와 추억 재발견.
8. **피드 카드의 '놀러가기' 동선**: 모든 피드 카드에서 그 사람의 공간/다이어리/사진첩으로 바로 이동.

## 4. 아직 비어 있는 것 (우선순위 순)

| 우선순위 | 과제 | 이유 |
|---|---|---|
| P0 | **쪽지(1:1 메시지)** | 사적 소통 수요가 가장 큼. 차단/신고/rate limit 구조는 이미 준비됨 |
| P0 | 비밀번호 재설정·이메일 인증 | 출시 필수 (메일 발송 인프라 필요) |
| P1 | **아이템 선물하기** | 싸이월드 '선물' 감성 + 친구 관계 강화 루프 (UserItem/CoinTransaction 구조 재사용) |
| P1 | 2D 미니룸 꾸미기(가구·벽지·바닥 아이템) | 상점 카탈로그에 `room:*` 슬롯 추가로 확장 |
| P1 | 웹 푸시 알림(PWA) + 홈 화면 위젯 | Locket식 '친구가 내 화면에' 경험. 알림 피로 방지 설정과 함께 |
| P2 | 관리자 신고 처리 화면 | Report 모델/상태값은 준비됨 |
| P2 | 이미지 스토리지 S3/R2 + CDN, 비공개 미디어 서명 URL | 현재는 추측 불가능한 키 기반 로컬 스토리지 |
| P2 | 검색 고도화(pg_trgm → 검색 엔진) | 검색 모듈을 한 곳으로 분리해 둠 |
| P3 | 3D 공간(React Three Fiber) | 미니룸 컴포넌트를 3D 모듈로 교체하는 구조 |
