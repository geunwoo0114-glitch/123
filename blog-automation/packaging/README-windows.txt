블로그 자동화 프로그램 (윈도우)
================================

1. blog-app.exe 를 더블클릭하세요. (Node.js 설치 필요 없음)
   - "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]
2. 브라우저에 프로그램 화면이 자동으로 열립니다. (안 열리면 http://localhost:4848)
3. [설정] 탭에서 Claude API 키를 넣거나 내 컴퓨터 AI(Ollama)를 고르세요.
4. [글쓰기] 탭에서 주제를 적고 버튼을 누르면 끝!

- 검은 창을 닫으면 프로그램이 꺼집니다.
- 내 설정(settings.json)과 쓴 글(posts 폴더)은 이 폴더에 저장됩니다.
  settings.json 에는 API 키가 들어 있으니 다른 사람에게 보내지 마세요.
- 새 버전으로 바꿀 때는 blog-app.exe 만 바꾸면 설정과 글이 그대로 남습니다.
