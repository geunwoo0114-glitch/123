블로그 자동화 프로그램 (맥)
============================

1. blog-app 파일을 [우클릭(또는 control+클릭)] → [열기] → [열기] 를 누르세요. (Node.js 설치 필요 없음)
   - 처음 한 번만 이렇게 열면 되고, 다음부터는 더블클릭하면 됩니다.
   - "Apple이 확인할 수 없습니다" 창만 뜨고 [열기] 버튼이 없으면:
     시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "blog-app" 옆 [그래도 열기]
2. 터미널 창이 뜨고, 브라우저에 프로그램 화면이 자동으로 열립니다. (안 열리면 http://localhost:4848)
3. [설정] 탭에서 Claude API 키를 넣거나 내 컴퓨터 AI(Ollama)를 고르세요.
4. [글쓰기] 탭에서 주제를 적고 버튼을 누르면 끝!

- 터미널 창을 닫으면 프로그램이 꺼집니다.
- 내 설정(settings.json)과 쓴 글(posts 폴더)은 이 폴더에 저장됩니다.
  settings.json 에는 API 키가 들어 있으니 다른 사람에게 보내지 마세요.
- 애플 실리콘(M1 이후)과 인텔 맥 모두에서 동작합니다.
