내 글

AI가 쓴 글은 모두 여기에 저장됩니다. 눌러서 읽고, 고치고, 발행하세요.

    글감 목록

    미리 주제를 쌓아 두면 주제를 비운 채 "글 쓰기"를 누를 때마다 위에서부터 하나씩 씁니다.

      1. AI 연결

      기본으로 쓸 AI를 고르세요. 글쓰기 화면에서 매번 바꿀 수도 있어요.

      Claude

      1. console.anthropic.com에 가입하고 결제 수단을 등록합니다.
      2. API Keys → Create Key로 키를 만들어 아래에 붙여 넣습니다. (키는 이 컴퓨터에만 저장돼요)

      내 컴퓨터 AI (Ollama)

      1. ollama.com에서 Ollama를 설치하고 실행합니다.
      2. 터미널(명령 프롬프트)에서 ollama pull qwen2.5:7b 처럼 모델을 받습니다. 한국어는 qwen2.5·gemma 계열을 추천해요.

      2. 내 블로그 성격

      AI가 이 내용을 보고 내 블로그에 맞는 글을 씁니다.

      3. 발행할 곳 (선택)

      비워 두면 글은 "내 글"에만 저장되고, 서식째 복사로 네이버 블로그·티스토리 편집기에 붙여 넣을 수 있어요.

      WordPress

      1. WordPress 관리자 → 사용자 → 프로필 → 애플리케이션 비밀번호에서 새 비밀번호를 만듭니다.

      웹훅 (Make·Zapier·n8n 연결용, 잘 모르면 비워 두세요)
